# Roadmap

## Near term

- Portfolio weights and vectorized P&L aggregation on `bind` outputs.
- Monte Carlo VaR / ES and `method=skewed` extensions beyond Gaussian tails.
- Numeric literal bindings (constants) inside scripts.

## Medium term

- `groupby`-style workflows for multi-ticker panels (e.g. a `ticker` column).
- Scenario-shock DSL (per-element scaling and shifts).

## Long term

- Optional static typing (Legend-style) and schema validation.
- Lazy loads from warehouses (Snowflake and similar).
