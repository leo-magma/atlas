Overview

Atlas Suite UI — run DSL scripts with live progress, logs, and input inspection.

What is Atlas Suite?

Atlas Suite is a collection of sibling DSL runtimes focused on quantitative finance workflows. Each DSL is a small, line-oriented language that executes a pipeline of named steps (load → transform → compute → print). This UI lets you upload scripts, run them, and inspect artifacts (inputs, output, errors) in a reproducible way.

DSLs

Each page is dedicated to a DSL. Scripts are executed from their upload folder so relative load "x.csv" references work when you upload the CSV next to the script.
Atlas (.atl)
Risk scripting: returns, volatility, VaR/ES, corr/cov, beta, Sharpe, drawdown, min-var / tangency / efficient frontier.
Chronos (.chr)
Time-series ETL: load/clean/join/resample/shift/diff/normalize + validation.
Hydra (.hyd)
Options analytics: Black–Scholes pricing, Greeks, implied volatility.
Neptune (.nep)
Fixed-income analytics: curve/bond loaders and standard bond measures.
Athena (.ath)
ML layer: features → train/predict/evaluate/backtest, model IO (optional deps).

How to use this UI

1) Upload
Pick a DSL, upload a script file, and optionally upload CSV/data files referenced by load.
2) Run
Jobs start immediately (local thread). Optionally enable async workers via Celery.
3) Observe
Progress updates continuously. Output and errors stream in near real-time.
4) Inspect inputs
Job detail pages let you view the script and only the data files actually used by load.
